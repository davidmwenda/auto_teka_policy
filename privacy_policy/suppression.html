Suppression du compte

Le nom de la société exploitante n’est pas dans le code de l’application. Les coordonnées ci-dessous sont celles affichées dans OTOTEKA. Confirmez-les avant de considérer cette page comme le contact officiel.

Dans l’application

  1. Ouvrez OTOTEKA et connectez-vous avec l’e-mail et le mot de passe du compte.
  2. Allez dans Mon profil.
  3. Choisissez Supprimer mon compte et confirmez.

Cette action est définitive pour le compte d’authentification. Si vous avez oublié le mot de passe, utilisez d’abord « mot de passe oublié » sur l’écran de connexion.

Ce que la suppression retire

  • Le compte (adresse e-mail d’authentification).
  • La boutique liée à ce compte, ses annonces et les lignes de documents (pièce d’identité, RCCM).
  • Les fichiers de logo, de pièces et de documents dont le dossier correspond à ce compte, lorsque le nettoyage du stockage réussit.
  • Les véhicules enregistrés dans le garage.
  • Les recherches spéciales de ce compte et le numéro de téléphone qui y est associé.

Ce qui peut rester

  • Les photos déposées dans l’espace special-search-photos : la fonction actuelle ne les supprime pas.
  • Le cache de décodage VIN, qui n’est pas rattaché à un compte et peut servir à d’autres utilisateurs.

Il n’existe pas, dans l’application, de délai automatique après lequel toutes les données sont effacées.

Si vous ne pouvez pas ouvrir l’application

Écrivez à hello@autoteka.cd avec l’objet « Suppression de compte OTOTEKA » et l’adresse e-mail du compte. Cette adresse est celle affichée dans l’application. Son suivi réel reste à confirmer par l’éditeur.
